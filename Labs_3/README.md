# Лабораторная работа: Проверка выражений (Скобочная последовательность)

## Описание проекта

Стек работает по принципу **LIFO (Last In — First Out / "последним пришел — первым ушел")**.
Алгоритм последовательно анализирует строку: открывающие скобки помещаются на вершину стека, а при обнаружении закрывающей скобки проверяется её соответствие элементу на вершине. Если типы совпадают, элемент удаляется из стека.

## Функционал (Реализованные методы)

**Обязательная часть:**
	check_brackets(expression) — основная функция проверки корректности строки.
	Поддержка трёх основных типов скобок: `()`, `[]`, `{}`.

**Вариативная часть:**
	 Пункт 9: Отображение содержимого стека на каждом шаге (позволяет визуализировать процесс анализа строки в консоли).

## Принцип работы алгоритма

Внутри алгоритма используется один стек для отслеживания парности символов.

1. При чтении открывающей скобки (    (, `[`, {    ), элемент мгновенно падает на вершину стека. При этом в консоль выводится обновленное состояние структуры.
2. При чтении закрывающей скобки (  ), ], }  ):
	 1) Если стек пуст или тип скобки на вершине не совпадает с текущим — выражение неправильное (фиксируется ошибка).
	 2) Если типы совпадают — верхний элемент извлекается из стека, сигнализируя об успешно закрытой паре.
	 3) Игнорирование лишнего: Любые символы, не являющиеся скобками, алгоритм просто пропускает, двигаясь дальше.
3. Финальная проверка: Если после прохода по всей строке стек оказался абсолютно пустым — выражение полностью **корректно**.
