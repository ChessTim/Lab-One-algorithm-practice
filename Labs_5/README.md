**Лабораторная работа №5: Простые деревья**
## Задача 3 - Обход бинарного дерева

### Описание

Дано произвольное бинарное дерево (не обязательно дерево поиска). Требуется реализовать различные методы обхода и вычислить некоторые свойства дерева.

---

### Обязательная часть

Реализовать функции:
- `preorder(root)`, `inorder(root)`, `postorder(root)`: прямой, симметричный и обратный обходы, возвращающие список значений.
- `level_order(root)`: обход в ширину (BFS), выводящий элементы по уровням.
- Создать несколько тестовых деревьев для проверки работы функций.

### Вариативная часть

3. Найти максимальное и минимальное значения в дереве.

---

### Описание реализации кода


1. Класс Node — базовый класс для создания узла дерева, хранит значение и две ссылки (на левого и правого потомка).
2. Функции `pryamoy`, `simmetr` и `obratniy` — реализуют обходы в глубину через стандартную рекурсию. Чтобы не использовать сложные встроенные методы Python, списки склеиваются с помощью простых циклов for.
3. Функция `v_shirinu` — реализует обход по уровням (в ширину). Для этого используется обычный список, который выполняет роль очереди.
4. Функции `poisk_min` и `poisk_max` — находят экстремумы в дереве. Так как дерево не является деревом поиска, они проверяют абсолютно все узлы. Для упрощения проверок на пустые узлы используются очень большие и маленькие числа-заглушки.

### Результаты тестирования

Для проверки работы программы в коде было создано бинарное дерево со следующей структурой:
- Корень: 10
- Левый потомок: 5 (у него дети: 2 и 7)
- Правый потомок: 15

При запуске программа выводит правильные последовательности обходов, а также верно определяет минимальный элемент (2) и максимальный элемент (15).
