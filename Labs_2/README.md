# Лабораторная работа №2: Музыкальный плейлист

## Что делает программа
Это простой плеер на Python для управления треками. У каждой песни есть название, длительность в секундах, жанр и оценка (рейтинг).

### Функции в коде:
 Добавление трека в конец списка (`add_track`)
 Удаление трека по его номеру (`remove_track`)
 Перемешивание всех песен в случайном порядке (`shuffle_playlist`)
 Смена режима повтора: выкл, один трек, все треки (`set_repeat`)
 **Задание 2:** Загрузка готового плейлиста из файла Base64 (`load_from_base64_file`)
 **Задание 5:** Фильтр и поиск песен по конкретному жанру (`filter_by_genre`)

## Обоснование структуры данных
Я использовал **динамический массив** (обычный `list` в Python).

**Почему это лучше, чем связный список (LinkedList):**
1. В плейлисте постоянно нужен быстрый доступ по номеру (например, удалить 3-й трек или включить случайный). Массив находит элемент сразу, а в LinkedList пришлось бы перебирать все песни с самого начала.
2. Перемешивание (`random.shuffle`) работает из коробки только с массивами. На связном списке сделать это нормально очень сложно.
3. Массив не тратит лишнюю память на стрелочки-ссылки между элементами и быстрее перебирает песни при поиске жанра.

---

## Какие граничные случаи учтены
 Программа не падает, если попытаться удалить трек из пустого плейлиста или ввести несуществующий номер.
 Есть проверка на количество треков: если песня одна или список пустой, перемешивание просто не запустится.
 При чтении файла программа не вылетит с ошибкой, если самого файла нет на компьютере или в нем есть пустые строчки.
