## Лабораторная работа №4: Словари и хэш-таблицы (Map). Задача 2. Электронный журнал группы
### Описание задачи
Необходимо реализовать простой электронный журнал. Система хранит студентов и их баллы. Для каждого студента нужно быстро получать текущий результат по имени.

### Обязательная часть
В программе полностью реализованы следующие пункты:
* **добавление студента в журнал:** реализовано в пункте меню №2, при вводе нового имени создается новая запись в словаре.
* **выставление или обновление балла:** реализовано в пункте меню №2 через синтаксис `journal[name] = score`. Если студент уже существует, его старый результат перезаписывается.
* **получение балла по имени:** реализовано в пункте меню №3, программа проверяет наличие ключа через оператор `if name in journal`.
* **вывод всех студентов и их результатов:** реализовано в пункте меню №1 с помощью последовательного обхода ключей словаря в цикле `for student in journal`.

### Вариативная часть
* **3. Находить студента с минимальным баллом:** реализован алгоритм поиска минимума. Программа в цикле перебирает всех студентов, сравнивает их баллы и находит человека с самым низким результатом.
